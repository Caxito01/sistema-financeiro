Configurar Conexão Supabase
Cole as credenciais do seu projeto Supabase para conectar o portal aos seus dados reais. As informações ficam salvas apenas no seu navegador (localStorage).
Encontre essas informações em supabase.com/dashboard → Settings → API. A anon key é segura para uso no frontend.
