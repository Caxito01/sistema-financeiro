📚 Guia de Configurações
🎯 Visão Geral

A página de Configurações permite organizar seus lançamentos financeiros em uma estrutura hierárquica de 3 níveis que pode ser organizado da forma que preferir:

Grupo → Subgrupo → Classe
Exemplo 1: DESPESAS → IMÓVEL → Energia Elétrica
Exemplo 2: DESPESAS COM FILHOS → CARLOS EDU → Faculdade
🔧 Como usar a Hierarquia
➕
Criar Novo Item
Clique no botão Novo Grupo / Novo Subgrupo / Nova Classe conforme o nível atual. Preencha o nome e salve.
✏️
Editar Item
Passe o mouse sobre o item na lista e clique em ✏️ para abrir o formulário de edição.
🗑️
Excluir Item
Clique em 🗑️. Itens com dependências (subgrupos/classes vinculados) não podem ser excluídos.
⏸️
Ativar / Desativar
Use ⏸️ para desativar ou ▶️ para reativar. Itens inativos não aparecem nos lançamentos.
🌳 Navegação em Árvore

A hierarquia funciona como uma árvore navegável:

▶️
Clique no nome de um Grupo para ver seus Subgrupos
🔍
